# Feeling Fabric

An interactive MA creative project exploring love through textiles.

Visitors choose three words, create a fabric using the editor, explore fifty artist textile studies, and preview a personalized patch kit to stitch by hand and give as a gift. The editor includes all fifty original editable studies, 196 cut patterns, twelve layers, free colour selection, fabric textures, cutouts, stitches and handmade details.

## Visit

Use the website link in this repository’s About section. GitHub Pages serves `index.html` from the root of the `main` branch.

## Run locally

```sh
python3 -m http.server 8876
```

Open http://127.0.0.1:8876/ . No build step or package installation is required.

## Storage

Drafts and contributions are stored only in each visitor’s browser. They are not shared between devices or visitors. Download PNG or SVG copies from the preview page. Patch kits are shown as customizable previews. Visitors can download the kit preview; no order or payment is submitted.

## Project files

`app.js` contains the complete frontend source and artist recipes. `style.css` and `editorial.css` provide the styling. All images and mapped data are included, and relative URLs support GitHub Pages project paths.

No personal browser drafts, participant contributions, local server records, credentials or workstation paths are included.

## Research context

The study map uses the supplied Study 3 Default-condition summary (n=45) from Thorne, Hegarty & Hepper (2021), DOI: https://doi.org/10.1111/bjso.12422 . The supplied extract is not the paper’s screened final analysis. Colour and textile interpretations are artistic expressions.
